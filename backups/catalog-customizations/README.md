# Respaldos públicos del catálogo

La sincronización conserva aquí versiones anteriores validadas de precios y fotos antes de reemplazarlas. Estos archivos no forman parte del sitio publicado. Solo contienen datos que ya eran públicos; nunca claves ni contexto privado de administración. No se eliminan automáticamente.

Para recuperar uno, descarga su JSON y usa Administración → Respaldos → Restaurar archivo. La restauración necesita la clave y conserva los ajustes ajenos al archivo. Para incluir también el contexto y las fechas, descarga un respaldo completo desde el panel.

Un reinicio de revisión o una reducción superior al 50 % (incluido vaciar los ajustes) mantiene la copia estática anterior y avisa en Actions. Solo una ejecución manual con `allow_customization_reset` confirma ese reemplazo. La web sigue dando prioridad al Worker cuando está disponible.
