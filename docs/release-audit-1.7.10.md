# Lunivo 1.7.10 · etiquetas breves en inventario

Código 45. Se cambian únicamente las etiquetas de inventario: «Precio de venta» pasa a «Venta» y «Precio de compra» pasa a «Precio», tanto en las tarjetas como en sus detalles. Los importes, cálculos y datos guardados se conservan.

Validación: pruebas existentes de interfaz para precios de inventario, coincidencia con venta, filtros, preservación de datos y tarjetas compactas. Compilación pública Android y lintRelease. Verificación de firma conservada, manifiesto y hash del APK publicado; sin bootstrap privado de proveedores.
