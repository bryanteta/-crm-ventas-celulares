# Lunivo 1.7.9 · precios de compra y venta en inventario

Código 44. Las tarjetas del inventario global, Samuel, Split y Mis equipos muestran ambos importes: Precio de venta como valor principal y Precio de compra debajo. Sus detalles también identifican los dos precios. No se muestran las palabras costo, venta sugerida ni la explicación del aumento de $80.

El precio de venta conserva el cálculo existente con $80 por unidad. Las cotizaciones actualizadas se usan para los equipos preparados; consultar no modifica costos, precios personalizados, existencias ni ventas. El catálogo público conserva únicamente sus precios de venta.
